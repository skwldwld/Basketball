# WhatTheBall 🏀

## 소랑개
WhatTheBall은 Three.js와 Cannon.js를 사용하여 만든 3D 농구 게임입니다. 다양한 종류의 공을 선택하여 농구 골대에 던지는 재미있는 게임입니다.

## 주요 기능
- 다양한 공 선택 가능 (농구공, 눈덩이, 포켓몬볼, 볼링공, 방울토마토 등)
- 멀티플레이어 지원 (여러 플레이어가 번갈아가며 플레이)
- 실시간 점수 시스템
- 물리 기반의 공 움직임
- 3D 환경에서의 자유로운 시점 조작

## 게임 방법
1. 시작 화면에서 플레이어 수와 각 플레이어가 사용할 공을 선택합니다.
2. 게임이 시작되면 마우스로 시점을 조절할 수 있습니다.
3. 스페이스바를 눌러 공의 궤적을 조준합니다.
4. 스페이스바를 떼면 공이 발사됩니다.
5. 각 플레이어는 정해진 횟수만큼 공을 던질 수 있습니다.
6. 골대에 공을 넣으면 점수를 획득합니다.
7. 모든 플레이어의 턴이 끝나면 최종 점수를 확인할 수 있습니다.

## 기술 스택
- Three.js: 3D 그래픽스 렌더링
- Cannon.js: 물리 엔진
- Vite: 빌드 도구
- Firebase: 데이터베이스 및 호스팅

## 실행 방법
로컬 환경에서 실행하기:
```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```
